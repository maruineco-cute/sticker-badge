# ステッカーメーカー 🍃

画像をアップするだけで、**袋入りのダイカットステッカー / フレークシール / 缶バッジ**がつくれるWebアプリです。
ビルド不要・サーバー不要。`index.html` 1ファイルだけで動きます（処理はすべてブラウザ内で完結）。

## できること

- 画像をドラッグ＆ドロップ（複数枚OK・最大10枚）→ ステッカーに自動変身
- **変身 → 袋IN → ヘッダー → 完成** のアニメーション（効果は4種類＋ランダム）
- 白フチ・ぷっくり感・ラメ（ホロ）・フレークシール・缶バッジ（台紙つき）
- 商品名の色（チョコミント / ストロベリー / クッキークリーム / ブラックコーヒー / モノクロ系）
- 保存サイズ 3種類（900×1200 / 1080×1440 / 1800×2400）、動画保存、背景透過PNG
- モックアップ画像が3種類つくれます
  - 🏪 **店頭**（白い有孔ボードに吊るした売り場）
  - 📣 **SNS**（SNS投稿の画面）
  - 📱 **スマホ**（ショップの商品ページ画面・商品名と値段は自動連動）
- ステッカーは指でドラッグして袋の中の位置を調整できます（缶バッジは1個ずつ調整可）

## 使い方

1. `index.html` をブラウザで開く（ローカルでダブルクリックでもOK）
2. 右上の「設定」から画像をアップロード
3. 仕上がり・フチ・ラメを選んで「🎬 袋詰めから完成まで」を押す
4. 「⬇️ 画像を保存」「🎬 動画」「モックアップ」から書き出し

> iPhone / iPad は、保存ボタンまたは画像の長押しで写真に保存できます。

## GitHub Pages で公開する

### いちばん簡単（ブラウザだけで完結）

1. GitHub で **New repository** → リポジトリ名を入れて **Public** で作成
2. **Add file → Upload files** で、このフォルダの `index.html`（と `README.md`）をアップロード → **Commit changes**
3. リポジトリの **Settings → Pages**
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**
5. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開されます

### コマンドで

```bash
git init
git add .
git commit -m "ステッカーメーカー"
git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

そのあと Settings → Pages で `main` / `/ (root)` を選んで保存してください。

## メモ

- `.nojekyll` は GitHub Pages の Jekyll 処理を止めるための空ファイルです（消さないでください）
- 外部読み込みは Google Fonts（Mochiy Pop One）のみ。オフラインでも基本動作します
- アップロードした画像はサーバーに送信されません（すべて端末内で処理）
